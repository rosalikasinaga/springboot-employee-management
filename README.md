# Employee Management System

A backend REST API built with Spring Boot for managing employees and departments.  
This project uses Spring Data JPA and Microsoft SQL Server for data persistence.


## Features

- CRUD operations for Employees
- CRUD operations for Departments (Divisi)
- Relationship mapping (One-to-Many)
- RESTful API structure
- Automatic table generation using JPA


## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA (Hibernate)
- Microsoft SQL Server
- Maven
- Lombok
